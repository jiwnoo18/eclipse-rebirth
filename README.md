# ECLIPSE: REBIRTH

A mobile-friendly fantasy survival browser game built with HTML, CSS, and vanilla JavaScript.

## Play locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Controls
- **Desktop:** WASD or arrow keys to move, Space to strike, E to absorb a defeated monster, Q for Eclipse Burst.
- **Mobile:** use the on-screen joystick and action buttons.
- Defeat monsters, approach their remains, and tap **Absorb** to gain essence and experience.
- Gather **35 essence** to choose an evolution: Predator, Arcanist, or Warden.

## Publish with GitHub Pages
1. Open this repository on GitHub and select **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the Pages deployment. The site address will be shown in Settings → Pages and usually follows `https://jiwnoo18.github.io/eclipse-rebirth/`.

This is a playable prototype foundation; the world is generated locally in the browser and progress currently resets when the page reloads.
